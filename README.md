# projetoemgrupo # Animais Abandonados

## Tema
Animais abandonados nas cidades.

## Problema
O crescimento de animais abandonados em áreas urbanas tem se tornado um grande desafio. Muitos desses animais sofrem com fome, doenças e maus-tratos, além de representarem riscos à saúde pública e à segurança nas ruas.

## Solução
Desenvolvimento de um site com:
- Página de conscientização para informar a população sobre os impactos do abandono e incentivar a posse responsável.
- Formulário interativo para que usuários possam cadastrar animais,
